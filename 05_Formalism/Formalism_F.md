# Mathematical Formalism ($\mathcal{F}$)

The canonical structural engine is formulated as the 4-tuple:
$$\mathcal{F} \equiv \left\langle \mathcal{S}_{\text{adm}}, \mathcal{A}(\mathcal{R}), \mathcal{D}_t, \mathcal{O}_{\text{obs}} \right\rangle$$

## 1. Components
1. **Admissible Substrate ($\mathcal{S}_{\text{adm}}$):**
   $$\mathcal{S}_{\text{adm}} = \left\{ s \in \mathcal{S} \;\middle|\; \Pi_{C_{\text{adm}}}(s) = s \right\}$$
2. **Relational Algebra ($\mathcal{A}(\mathcal{R})$):**
   Non-commutative operator algebra generated by substrate adjacencies and gapped shear generators.
3. **Coarse-Graining Time Generator ($\mathcal{D}_t$):**
   Non-unitary dynamical semigroup generator defining flow toward emergent cosmological time:
   $$\mathcal{D}_t(\hat{\rho}) = -i[\hat{H}_0, \hat{\rho}] + \sum_k \left( L_k \hat{\rho} L_k^\dagger - \frac{1}{2} \{L_k^\dagger L_k, \hat{\rho}\} \right)$$
4. **Observable Set ($\mathcal{O}_{\text{obs}}$):**
   Macroscopic self-adjoint operators mapping micro-states to cosmological fluids.
